# OdinEye

> 🚧 У розробці

Легкий та гнучкий IP-аналізатор для SOC-команд. Дозволяє отримати деталізовану інформацію про IP-адреси та діапазони (RDAP, reverse DNS, ASN через Team Cymru) і сформувати результат у вигляді таблиці або PDF-звіту для передачі стороні, що запитала аналіз.

Хід розробки — у [`devlog.md`](./devlog.md).

## Стек

- Backend: Python, Flask
- Frontend: HTML/CSS/JS (без фреймворків)

## Запуск

```bash
pip install -r requirements.txt
python app.py
```
